# Security

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/zachaustin01/circa-million-tracker/security/advisories/new)
rather than a public issue.

This is an unofficial, read-only fan tracker. It has no accounts, no user input, and no server: the site is
static files built from Circa Sports' public selection PDFs and ESPN's public scoreboard. It is not affiliated
with Circa Sports. If you appear in the data (entry names come from Circa's public PDFs) and want to raise a
concern, open a security advisory or issue and it will be looked at.
